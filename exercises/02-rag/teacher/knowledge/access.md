# فعال‌سازی دسترسی

پس از تأیید پرداخت، دسترسی دوره معمولاً حداکثر تا پانزده دقیقه فعال می‌شود. فعال‌سازی موفق فقط به معنی باز شدن محتوای همان دوره است و به معنی تأیید بازگشت وجه نیست.
<!-- chunk -->
اگر پانزده دقیقه گذشت، کاربر باید شناسهٔ سفارش را برای بررسی وضعیت ارسال کند. این سند وضعیت واقعی هیچ حسابی را نشان نمی‌دهد.
