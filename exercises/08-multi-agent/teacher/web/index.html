دستیار اصلی و دو ایجنت متخصص

درخواست ترکیبی را به دستیار بدهید. دستیار اصلی تصمیم می‌گیرد کدام بخش را به متخصص بسپارد، گزارش‌ها را می‌گیرد و خودش پاسخ نهایی را می‌سازد.
