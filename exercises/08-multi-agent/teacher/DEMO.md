# دموی مدرس — تمرین ۸: واگذاری به ایجنت‌های متخصص

## اجرا

همان virtual environment تمرین ۷ و `.env` ریشه را استفاده کنید:

```bash
source .venv/bin/activate
python exercises/08-multi-agent/teacher/app.py
```

صفحه در `http://127.0.0.1:8788` باز می‌شود. تمرین از همان وابستگی ثبت‌شده در `exercises/07-pydantic-ai/requirements.txt` استفاده می‌کند.

## مسیر دموی اصلی

با کاربر `u-104` این درخواست ترکیبی را بفرستید:

> من دورهٔ مبانی یادگیری ماشین را خریده‌ام ولی دسترسی ندارم. برای شروع هوش مصنوعی هم چه دوره‌ای پیشنهاد می‌کنی؟

در UI نشان دهید:

1. برنامه، دستیار اصلی را با `SupportDeps` اجرا می‌کند.
2. دستیار اصلی `investigate_account` و `recommend_courses` را انتخاب می‌کند.
3. هر Tool یک Agent جدا را اجرا می‌کند؛ ایجنت حساب دو ابزار خواندنی خودش را به کار می‌گیرد و ایجنت کاتالوگ ابزار جست‌وجوی خودش را.
4. هر متخصص گزارش ساختاریافته برمی‌گرداند و دستیار اصلی گزارش‌ها را ترکیب می‌کند.

حالا همین درخواست را برای `u-208` اجرا کنید: پرداخت ناموفق است، پس دستیار نباید ادعای مغایرتِ پرداخت موفق با دسترسی خاموش بکند. سؤال عمومی و سؤال صرفاً آموزشی را هم بفرستید تا تصمیم دستیار برای واگذاری (یا ندادن واگذاری) دیده شود.

## مرز دسترسی

- `CatalogDeps` فقط کاتالوگ دوره‌ها را دارد.
- `AccountDeps` فقط شناسهٔ کاربر انتخاب‌شده و دادهٔ پرداخت و ثبت‌نام را دارد. توابع Python نیز فقط ردیف‌های همان شناسه را برمی‌گردانند.
- `SupportDeps` وابستگی‌های برنامه را نگه می‌دارد و در هر واگذاری، زیرمجموعهٔ لازم را به متخصص می‌دهد.

این جداسازی برای نمایش اصل **حداقل دسترسی لازم** است؛ UI انتخاب کاربر احراز هویت واقعی نیست.

## نکته‌های گفت‌وگو با کلاس

- Tool واگذاری یک wrapper ساده است که اجرای Agent متخصص را آغاز می‌کند؛ خود متخصص prompt، ابزار، context و خروجی جدا دارد.
- یک تابع معمولی برای خواندن یک ردیف، معمولاً ارزان‌تر و قابل‌پیش‌بینی‌تر است. Agent متخصص وقتی توجیه دارد که کارش به تفسیر، چند ابزار یا خلاصه‌سازی نیاز داشته باشد.
- هر واگذاری معمولاً فراخوانی‌های مدل و تأخیر بیشتری اضافه می‌کند. رد اجرا برای همین در UI نمایش داده می‌شود.
- متخصص‌ها به‌طور مستقیم با کاربر حرف نمی‌زنند؛ دستیار اصلی کنترل گفت‌وگو را نگه می‌دارد.
- هیچ داده‌ای در این تمرین نوشته یا تغییر داده نمی‌شود.
