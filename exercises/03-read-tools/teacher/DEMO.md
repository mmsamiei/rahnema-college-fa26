# دموی مدرس — تمرین ۳: خواندن اطلاعات با Tool Calling

زمان پیشنهادی: ۴۵ دقیقه. هدف نمایش مسیر واقعی tool call در کد ساده است؛ از هنرجوها بخواهید چشمشان را روی `agent.py` نگه دارند و همان مراحل را در ترمینال و صفحه دنبال کنند.

## اجرا

```bash
# ترمینال اول: نسخهٔ شرکت‌کننده
python3 exercises/03-read-tools/student/app.py

# ترمینال دوم: دموی مدرس
python3 exercises/03-read-tools/teacher/app.py
```

صفحه‌ها در `http://127.0.0.1:8777` و `http://127.0.0.1:8778` هستند. هر دو نسخه `.env` ریشه را می‌خوانند.

## مسیر پیشنهادی کلاس

| زمان | اجرا | نکته |
|---|---|---|
| ۰–۵ | سؤال «دسترسی en-1042 فعال است؟» | مدل درخواست ابزار می‌دهد؛ خودش JSON را نمی‌خواند |
| ۵–۱۵ | `TOOLS` را در `teacher/agent.py` نشان دهید | schema قرارداد میان برنامه و مدل است |
| ۱۵–۲۵ | `run_tool` و `get_enrollment_status` را دنبال کنید | برنامه نام ابزار را به تابع مجاز وصل و آن تابع فایل را می‌خواند |
| ۲۵–۳۵ | نتیجهٔ `tool` را به پیام‌ها اضافه کنید و درخواست دوم را نشان دهید | این مرحله مدل را قادر می‌کند نتیجه را به زبان طبیعی توضیح دهد |
| ۳۵–۴۵ | نسخهٔ خام دانشجو و دو خطایابی کوتاه | شناسهٔ ناموجود و سؤال عمومی را اجرا و تفاوت را بررسی کنید |

## سناریوها و رفتار مورد انتظار

| سؤال | ابزار | انتظار |
|---|---|---|
| ثبت‌نام `en-1042` فعال است؟ | `get_enrollment_status` | رکورد active و تاریخ اعتبار را گزارش کند |
| وضعیت سفارش `or-7702` چیست؟ | `get_payment_status` | وضعیت pending را پرداخت‌شده جلوه ندهد |
| ثبت‌نام `en-9999` را بررسی کن | `get_enrollment_status` | نبود رکورد را روشن بگوید |
| سلام، چه کمکی می‌کنی؟ | معمولاً هیچ‌کدام | پاسخ عمومی بدون خواندن داده |

## نکته‌های توضیح

- Tool Calling اجرای تابع در مدل نیست. مدل یک پیام ساخت‌یافته با نام تابع و آرگومان پیشنهاد می‌کند؛ برنامهٔ ما تابع Python را اجرا می‌کند.
- `TOOLS` اجازهٔ دسترسی مستقیم به فایل‌ها نمی‌دهد. dispatch برنامه فقط دو نام ثابت را می‌پذیرد.
- نتیجه با نقش `tool` و شناسهٔ همان درخواست به مدل برمی‌گردد؛ درخواست دوم برای ساخت پاسخ انسانی است.
- این نمونه هر بار فقط یک ابزار را اجرا می‌کند تا رفت‌وبرگشت روشن بماند. انتخاب چند ابزار، تکرار حلقه، نوشتن داده و تأیید کاربر موضوع تمرین‌های بعد هستند.
- همهٔ رکوردها ساختگی‌اند و نباید به‌عنوان دادهٔ واقعی کاربر یا وضعیت زنده معرفی شوند.
