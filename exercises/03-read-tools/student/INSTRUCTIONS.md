# تمرین ۳ — خواندن اطلاعات با Tool Calling

## مسئله

دستیارِ تمرین‌های قبل نمی‌توانست بداند ثبت‌نام یا پرداخت یک کاربر چه وضعی دارد. حالا چند رکورد ساختگی در فایل‌های JSON داریم و دو تابع Python می‌توانند آن‌ها را بخوانند. مدل خودش فایل را باز نمی‌کند: فقط درخواست یک ابزار با آرگومان مشخص می‌دهد؛ برنامه تابع را اجرا می‌کند و نتیجه را برای پاسخ‌دادن دوباره به مدل می‌فرستد.

```text
سؤال → درخواست ابزار از مدل → تابع Python → نتیجهٔ JSON → پاسخ مدل
```

## آماده‌سازی و اجرا

Python 3.9 یا جدیدتر کافی است. وابستگی تازه‌ای نصب نکنید. از ریشهٔ پروژه اجرا کنید:

```bash
python3 exercises/03-read-tools/student/app.py
```

صفحهٔ http://127.0.0.1:8777 را باز کنید. تنظیمات LLM از `.env` ریشهٔ پروژه خوانده می‌شوند. ترمینالی که سرور را اجرا کرده‌اید هم مراحل را چاپ می‌کند. برای توقف `Ctrl+C` بزنید.

## مأموریت: TODOها را به ترتیب کامل کنید

1. در `agent.py`، برای دو تابع `get_enrollment_status` و `get_payment_status`، تعریف ابزار سازگار با Chat Completions بنویسید. نام، توضیح و پارامترهای اجباری را مطابق امضای تابع‌ها وارد کنید.
2. دو تابع خواندن را با فایل‌های `data/enrollments.json` و `data/payments.json` کامل کنید. تابع باید بر اساس شناسهٔ داده‌شده رکورد را پیدا کند و اگر نبود، نتیجهٔ `found: false` برگرداند.
3. در `run_tool` نام تابعی را که مدل خواسته به یکی از دو تابع مجاز وصل کنید. تابع را با آرگومان‌های JSON فراخوانی کنید. نام فایل یا مسیر را از مدل نگیرید.
4. بعد از اجرای تابع، پیام درخواست ابزار را به گفت‌وگو اضافه کنید، نتیجه را با نقش `tool` و همان `tool_call_id` اضافه کنید و درخواست دوم مدل را بدون ابزار بفرستید. پاسخ نهایی و مراحل اجرا را برگردانید.

TODOها را یکی‌یکی کامل کنید و قبل از رفتن به مرحلهٔ بعد، از Coding Agent بخواهید تغییر را در کد توضیح دهد. بعد از تکمیل هر چهار TODO، صفحه را اجرا و سناریوهای زیر را امتحان کنید. Coding Agent هم می‌تواند TODOها را به همین ترتیب انجام دهد.

## سناریوها

- `ثبت‌نام en-1042 برای دوره فعال است؟` باید ابزار ثبت‌نام را با `enrollment_id` درست صدا بزند.
- `وضعیت پرداخت سفارش or-7702 چیست؟` باید ابزار پرداخت را با `order_id` درست صدا بزند.
- `وضعیت ثبت‌نام en-9999 را بگو.` باید نتیجهٔ «رکوردی پیدا نشد» را منتقل کند.
- برای «سلام، چه کمکی می‌کنی؟» معمولاً لازم نیست تابعی اجرا شود.

## محدودیت‌ها و تحویل

- در هر سؤال حداکثر یک ابزار خواندنی اجرا می‌شود. اجرای چند ابزار و تکرار خودکار مرحله‌ها به تمرین Agent Loop مربوط است.
- داده‌ها ساختگی‌اند؛ ابزارها فقط JSON محلی را می‌خوانند و هیچ چیزی را تغییر نمی‌دهند.
- تحویل: TODOهای تکمیل‌شده و توضیح کوتاه این‌که کدام مرحله درخواست مدل بود، کدام مرحله اجرای واقعی تابع Python بود، و چرا مدل به‌تنهایی نمی‌توانست وضعیت زنده را بداند.
