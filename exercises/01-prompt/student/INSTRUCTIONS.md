# تمرین ۱ — اولین دستیار پشتیبانی

## موقعیت

«رهنما» یک پلتفرم فرضی فروش دورهٔ آنلاین است. کاربران دربارهٔ انتخاب دوره، قانون بازگشت وجه، فعال شدن دسترسی و لغو سفارش می‌پرسند. در این مرحله دستیار **فقط به یک LLM وصل است**. هنوز هیچ قانون اختصاصی، دادهٔ ثبت‌نام یا ابزار اقدامی ندارد.

## راه‌اندازی روی رایانهٔ خودتان

Python 3.9 یا جدیدتر لازم است؛ نصب کتابخانهٔ دیگری نیاز نیست. اگر پروژه را هنوز ندارید، یک بار آن را دریافت کنید و وارد پوشه‌اش شوید:

```bash
git clone https://github.com/mmsamiei/rahnema-college-fa26.git
cd rahnema-college-fa26
```

اگر پروژه را از قبل دارید، دوباره clone نکنید؛ به همان پوشه بروید. اگر فایل `.env` ندارید، آن را از نمونه بسازید:

```bash
cp -n .env.example .env
```

سپس فایل `.env` را در یک ویرایشگر باز کنید و `LLM_BASE_URL`، `LLM_API_KEY` و `LLM_MODEL` را در آن پر کنید. مدرس می‌تواند تنظیمات را از قبل آماده کرده باشد؛ در آن صورت این مرحله را تکرار نکنید. کلید را داخل کد یا چت Coding Agent قرار ندهید.

سپس اجرا کنید:

```bash
python3 exercises/01-prompt/student/app.py
```

وقتی پیام `Open http://127.0.0.1:8765` را دیدید، صفحهٔ `http://127.0.0.1:8765` را در مرورگر باز کنید. ترمینال را هنگام کار باز نگه دارید. برای توقف، در همان ترمینال `Ctrl+C` بزنید. تغییر `prompt.py` با سؤال بعدی اعمال می‌شود و نیازی به اجرای مجدد نیست.

## مأموریت، قدم‌به‌قدم

1. طبق بخش «راه‌اندازی» برنامه را اجرا و صفحه را باز کنید.
2. چهار سؤال آماده را با prompt اولیه اجرا کنید. برای هر پاسخ یادداشت کنید مدل چه ادعایی کرد و آیا برای آن شواهدی داشت.
3. فقط مقدار `SYSTEM_PROMPT` در `prompt.py` را تغییر دهید. دستیار باید به فارسی، روشن و کمک‌کننده پاسخ دهد. وقتی اطلاعات اختصاصی لازم است، محدودیت خود را بیان کند و راه بعدی مناسب پیشنهاد دهد.
4. همان چهار سؤال را دوباره اجرا کنید. تغییرات `prompt.py` بدون راه‌اندازی مجدد سرور در سؤال بعدی اعمال می‌شود.
5. یک پاسخ مسئله‌دار پیدا کنید؛ مثلاً قانونی را بدون سند قطعی اعلام کرده یا گفته لغو انجام شد. prompt را اصلاح و دوباره آزمایش کنید.

## محدودیت‌ها

- قانون بازگشت وجه، وضعیت سفارش یا تاریخ فعال شدن دسترسی را حدس نزنید.
- ادعا نکنید لغو یا بازگشت وجه انجام شده است؛ هیچ ابزار اقدامی وجود ندارد.
- API key را داخل `prompt.py`، درخواست Coding Agent یا خروجی تمرین نگذارید.
- در این تمرین سند، RAG، ابزار و framework اضافه نکنید.

## استفاده از Coding Agent

می‌توانید از Coding Agent برای پیشنهاد یا اصلاح متن prompt کمک بگیرید. به او بگویید فقط `student/prompt.py` را تغییر دهد و همین محدودیت‌ها را رعایت کند. بعد خودتان چهار خروجی را ببینید و توضیح دهید کدام ادعاها قابل اتکا هستند. مسئولیت انتخاب prompt و ارزیابی پاسخ با شماست.

## تحویل کوتاه

متن prompt نهایی، یک نمونه پاسخ اولیه و اصلاح‌شده، و دو جمله دربارهٔ اینکه دستیار هنوز چه کاری نمی‌تواند انجام دهد.
