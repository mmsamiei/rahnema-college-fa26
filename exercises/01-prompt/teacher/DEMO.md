# دموی مدرس — تمرین ۱

زمان پیشنهادی: ۴۵ تا ۵۰ دقیقه. نسخهٔ خام را روی پورت ۸۷۶۵ و نسخهٔ مدرس را روی پورت ۸۷۶۶ اجرا کنید. از یک مدل و سؤال‌های یکسان استفاده کنید. خروجی دقیق LLM از قبل تضمین‌شده نیست؛ دربارهٔ ادعا و شواهد آن گفت‌وگو کنید، نه تطبیق واژه‌به‌واژه.

## اجرای دستی دو نسخه

فایل `.env` را در ریشهٔ پروژه تنظیم کنید. اگر پروژه را در مسیر دیگری clone کرده‌اید، آن مسیر را در دستور `cd` جایگزین کنید. دو ترمینال باز کنید؛ هر کدام باید باز بماند.

ترمینال اول، نسخهٔ خام:

```bash
cd rahnema-college-fa26
python3 exercises/01-prompt/student/app.py
```

ترمینال دوم، نسخهٔ مدرس:

```bash
cd rahnema-college-fa26
python3 exercises/01-prompt/teacher/app.py
```

صفحه‌ها به‌ترتیب `http://127.0.0.1:8765` و `http://127.0.0.1:8766` هستند. برای توقف هر نسخه در ترمینال خودش `Ctrl+C` بزنید.

## رفتار مورد انتظار در چهار سؤال

1. **سؤال عمومی دربارهٔ انتخاب دوره:** پاسخ کاربردی و کوتاه بدهد؛ برای پیشنهاد شخصی‌تر، هدف و سطح کاربر را بپرسد. ادعای داشتن فهرست دوره‌های رهنما نکند.
2. **قانون بازگشت وجه:** بگوید قانون اختصاصی در اختیارش نیست و شرایط قطعی یا مهلت ساختگی ندهد.
3. **فعال شدن دسترسی:** روشن کند به اطلاعات ثبت‌نام کاربر دسترسی ندارد؛ شماره سفارش، حساب یا پشتیبانی را به‌عنوان مسیر بررسی پیشنهاد کند، بدون درخواست اطلاعات حساس.
4. **لغو و بازگشت وجه:** نگوید کاری انجام شده؛ توضیح دهد در این مرحله امکان اقدام ندارد.

اگر نسخهٔ خام هم پاسخ محتاطانه داد، آن را موفقیت اولیهٔ مدل بدانید و سؤال را دقیق‌تر کنید: «از کجا فهمیدی؟». تفاوت آموزشی این است که نسخهٔ مدرس مرز دانش و اختیار را صریح و پایدارتر بیان می‌کند. برای دموی کوتاه، پرسش دوم یا چهارم را یک بار دیگر اجرا کنید تا تغییرپذیری پاسخ نیز دیده شود.

برای نشان دادن چندنوبته بودن، پس از سؤال بازگشت وجه در **همان گفت‌وگو** بپرسید: «این مهلت را از کجا آوردی؟». مدل در نوبت دوم سؤال و پاسخ قبلی را می‌بیند. سپس «گفت‌وگوی تازه» را بزنید و نشان دهید که آن سابقه دیگر در درخواست بعدی نیست. تاریخچه در همان تب مرورگر می‌ماند و پس از ۱۰ نوبت باید پاک شود؛ این هنوز حافظهٔ بلندمدت نیست.

## نکات اجرایی

- `.env` فقط در ریشهٔ پروژه است. آن را نمایش ندهید و به دانشجو تحویل ندهید.
- صفحهٔ هر نسخه عنوان جداگانه دارد؛ هر دو سؤال‌های یکسان را اجرا می‌کنند.
- تغییر `prompt.py` با سؤال بعدی اعمال می‌شود.
- هر درخواست API ممکن است هزینه داشته باشد. برای صرفه‌جویی، سؤال‌های آماده را به‌ترتیب و فقط هنگام نیاز دوباره اجرا کنید.
