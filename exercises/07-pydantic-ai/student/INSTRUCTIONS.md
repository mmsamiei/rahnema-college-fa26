# تمرین ۷ — ساخت Agent و رساندن Deps به Tool

## مسئله

دستیار باید وضعیت دسترسی کاربر انتخاب‌شده به دورهٔ «مبانی یادگیری ماشین» را گزارش کند. دادهٔ JSON و صفحهٔ آزمایش آماده است. کار شما در این مرحله کامل‌کردن دو بخش در `student/agent.py` است.

## راه‌اندازی

از ریشهٔ مخزن، محیط Python مخصوص تمرین را بسازید و وابستگی را نصب کنید:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

تنظیمات `LLM_BASE_URL`، `LLM_API_KEY` و `LLM_MODEL` را در `.env` ریشه قرار دهید. سپس صفحه را اجرا کنید:

```bash
python exercises/07-pydantic-ai/student/app.py
```

برای این تمرین Python 3.10 یا جدیدتر لازم است؛ این دمو با `python3.12` آزمایش شده است. صفحه در `http://127.0.0.1:8785` باز می‌شود. با `Ctrl+C` سرور را متوقف کنید.

## کارهایی که باید انجام دهید

در `student/agent.py`:

1. در TODO 1، `SupportDeps` را به dataclass تبدیل کنید تا `user_id` و `course_data` را نگه دارد.
2. در TODO 2، یک `Agent` با `deps_type=SupportDeps` بسازید و با `@agent.tool` تابع `get_course_access` را ثبت کنید. تابع باید `RunContext[SupportDeps]` بگیرد، رکورد کاربر و دوره را پیدا کند و اگر نبود نتیجهٔ `found=False` بدهد.
3. بررسی کنید `answer()` همان `SupportDeps` را با `deps=...` به `run_sync` می‌دهد.

از فهرست داده‌ها فقط رکوردی را برگردانید که `user_id` آن با `ctx.deps.user_id` یکی است. این انتخاب در تمرین هویت آزمایشی است و احراز هویت واقعی نیست.

## آزمایش و تحویل

سؤال آماده را برای `u-104` و `u-208` بفرستید. رد اجرا باید Tool call و نتیجهٔ آن را پیش از پاسخ نهایی نشان دهد. توضیح دهید `user_id` در کجا ساخته شد و در کدام خط Tool به آن دسترسی پیدا کرد.

داده‌ها عمداً دو نتیجهٔ متفاوت دارند: دسترسی `u-104` غیرفعال و دسترسی `u-208` فعال است. انتظار نداریم متن پاسخ مدل دقیقاً یکسان یا ثابت باشد؛ وضعیت گزارش‌شده باید با نتیجهٔ Tool هماهنگ باشد.
