# دموی مدرس — تمرین ۷: Agent و Deps با Pydantic AI

## آماده‌سازی و اجرا

از ریشهٔ مخزن، یک‌بار محیط تمرین را آماده کنید:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

تنظیمات LLM را در `.env` ریشه کامل کنید. برای اجرای نسخهٔ مدرس:

```bash
python exercises/07-pydantic-ai/teacher/app.py
```

صفحه در `http://127.0.0.1:8786` باز می‌شود. برای توقف سرور `Ctrl+C` بزنید.

تست آفلاین مسیر Agent و Deps:

```bash
python -m unittest discover -s exercises/07-pydantic-ai/tests -v
```

## اجرای دمو

سؤال «وضعیت دسترسی من به دورهٔ مبانی یادگیری ماشین چیست؟» را یک‌بار برای `u-104` و یک‌بار برای `u-208` بفرستید. در رد اجرا نشان دهید:

1. سرور `SupportDeps` را با کاربر انتخاب‌شده می‌سازد.
2. Agent، Tool ثبت‌شده را در اختیار مدل می‌گذارد.
3. مدل Tool را انتخاب می‌کند و `ctx.deps` دادهٔ همان کاربر را تعیین می‌کند.
4. Pydantic AI نتیجهٔ Tool را به مدل می‌دهد تا پاسخ نهایی ساخته شود.

## نکته‌های تدریس

- `deps` به‌خودی‌خود prompt یا متن قابل‌مشاهده برای مدل نیست؛ کد Python آن را از `ctx.deps` می‌خواند.
- تابع Tool با decorator به Agent ثبت می‌شود و امضای تابع، نام و آرگومان‌های Tool را شکل می‌دهد.
- انتخاب user در این دمو فقط هویت آزمایشی است، نه احراز هویت واقعی.
- درخواست واقعی فقط در دمو انجام می‌شود؛ تست‌های خودکار با مدل آزمایشی Pydantic AI آفلاین‌اند.
