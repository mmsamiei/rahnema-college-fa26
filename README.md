# Rahnema College — کارگاه ساخت دستیار هوشمند

در این کارگاه، یک دستیار پشتیبانی برای پلتفرم فرضی فروش دورهٔ «رهنما» را مرحله‌به‌مرحله می‌سازیم. هر تمرین دو نسخهٔ مستقل دارد: `student` برای شرکت‌کننده و `teacher` برای دموی مدرس.

## شروع تمرین اول

Python 3.9 یا جدیدتر کافی است و نصب کتابخانه لازم نیست. پروژه را یک بار دریافت کنید:

```bash
git clone https://github.com/mmsamiei/rahnema-college-fa26.git
cd rahnema-college-fa26
cp -n .env.example .env
```

اگر پروژه را از قبل دارید، فقط به پوشهٔ آن بروید و `git pull` بزنید. در فایل `.env`، URL، کلید و نام مدل را قرار دهید. سرویس باید API سازگار با OpenAI Chat Completions داشته باشد. کلید را در صفحهٔ مرورگر، فایل‌های تمرین یا commit قرار ندهید؛ `.env` در `.gitignore` است.

نسخهٔ شرکت‌کننده:

```bash
python3 exercises/01-prompt/student/app.py
```

نسخهٔ مدرس (روی پورت دیگر):

```bash
python3 exercises/01-prompt/teacher/app.py
```

صفحهٔ شرکت‌کننده در `http://127.0.0.1:8765` و صفحهٔ مدرس در `http://127.0.0.1:8766` باز می‌شود. برای توقف سرور `Ctrl+C` بزنید. اگر هر دو را هم‌زمان اجرا می‌کنید، دو ترمینال باز کنید.

هر صفحه گفت‌وگوی چندنوبته دارد: پیام‌های قبلی در صفحه دیده می‌شوند و همراه پیام تازه به مدل فرستاده می‌شوند. برای مقایسهٔ مستقل سؤال‌های آماده یا شروع آزمایش جدید، «گفت‌وگوی تازه» را بزنید. تاریخچه فقط در همان تب مرورگر نگه داشته می‌شود؛ این تمرین هنوز حافظهٔ کاربر بین جلسه‌ها ندارد.

ابتدا [راهنمای شرکت‌کننده](exercises/01-prompt/student/INSTRUCTIONS.md) یا [سناریوی دموی مدرس](exercises/01-prompt/teacher/DEMO.md) را بخوانید. هر پرسش به API مدل ارسال می‌شود و ممکن است هزینه داشته باشد. اگر `.env` هنوز آماده نیست، صفحه باز می‌شود اما هنگام ارسال سؤال، پیام تنظیمات را نشان می‌دهد.

کد اجرایی این مرحله در `exercises/01-prompt/runtime.py` است. هر دو نسخهٔ `student` و `teacher` از آن استفاده می‌کنند و فقط prompt و عنوان صفحهٔ خود را دارند. در تمرین‌های بعدی، کد اجرایی همان مرحله داخل پوشهٔ خودش خواهد بود تا بتوان آن را برای RAG، گفت‌وگوی چندنوبته و agent loop تغییر داد.

## تمرین ۲: RAG

تمرین دوم سه نوع قطعه‌بندی policyها را پیش از تماس با مدل مقایسه می‌کند: سند کامل، برش خودکار با overlap و مرز دستی. هیچ embedding، vector DB یا Docker لازم نیست.

```bash
python3 exercises/02-rag/student/app.py
```

نسخهٔ دانشجو در `http://127.0.0.1:8775` و دموی مدرس در `http://127.0.0.1:8776` است. راهنمای دانشجو در [تمرین RAG](exercises/02-rag/student/INSTRUCTIONS.md) و سناریوی کلاس در [دموی مدرس](exercises/02-rag/teacher/DEMO.md) قرار دارد.

## تمرین ۷: Agent و Deps با Pydantic AI

این تمرین یک Agent و یک ابزار خواندنی را با Pydantic AI می‌سازد. دانشجو می‌بیند `deps` چطور از اجرای Agent به ابزار می‌رسد و خود framework رفت‌وبرگشت ابزار را مدیریت می‌کند.

یک virtual environment بسازید و وابستگی تمرین را نصب کنید:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r exercises/07-pydantic-ai/requirements.txt
```

نسخهٔ دانشجو در `http://127.0.0.1:8785` و دموی مدرس در `http://127.0.0.1:8786` اجرا می‌شوند. هر نسخه را در ترمینال جدا اجرا کنید:

```bash
.venv/bin/python exercises/07-pydantic-ai/student/app.py
.venv/bin/python exercises/07-pydantic-ai/teacher/app.py
```

راهنمای دانشجو در [تمرین Pydantic AI](exercises/07-pydantic-ai/student/INSTRUCTIONS.md) و راهنمای دموی مدرس در [سناریوی مدرس](exercises/07-pydantic-ai/teacher/DEMO.md) است.
